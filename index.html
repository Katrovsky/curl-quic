cURL with HTTP/3 & QUIC

Custom OpenWrt APK Repository for aarch64_cortex-a53

HTTP/3 (QUIC) OpenWrt 25.12+ / APK ngtcp2 + nghttp3 + QuicTLS Static Bundle

Quick Installation on OpenWrt

1. Import the repository public signing key:
wget -O /etc/apk/keys/curl-quic.pub https://REPLACE_URL/curl-quic.pub
2. Add the repository to apk sources:
echo "https://REPLACE_URL/aarch64_cortex-a53/packages.adb" > /etc/apk/repositories.d/curl-quic.list
3. Update index and install:
apk update
apk add curl-quic

Verify HTTP/3 Support

Check version and features:
curl --version
Test a real HTTP/3 connection:
curl --http3 -I https://cloudflare-quic.com

About this build

This build bundles QuicTLS, nghttp3, and ngtcp2 statically into curl. It will never conflict with or overwrite the router's system libssl or mbedtls libraries, ensuring 100% stability and zero dependency issues.

Built automatically via GitHub Actions CI/CD.
